## 4. Lỗ hổng & vì sao VÁ ĐƯỢC (đọc kỹ phần này khi tự ti)

| Lỗ hổng | Thực tế | Vì sao không đáng sợ |
|---------|---------|----------------------|
| **Code nền "rỉ sét", quen dựa AI** | Sẽ lộ ở vòng live-coding / hỏi sâu React | Đây là **nhớ lại**, không phải học từ 0. 2-3 tuần ôn là khác hẳn |
| **Giao tiếp English yếu** | Chặn job remote/quốc tế | Đọc/viết kỹ thuật anh đã ổn; job VN không cần. Luyện nói dần |

## 5. Câu hỏi hay gặp + dùng câu chuyện nào (STAR)

- **"Kể về một dự án anh tự hào nhất."** → EmoEase. *Tình huống:* tự sáng lập app sức khỏe tinh thần. *Việc:* dựng UI + tích hợp 80+ API. *Hành động:* dùng React Query (cache/retry/sync) để app ổn định. *Kết quả:* **1,000+ users**, được chọn UNIVENTURES 2025.
- **"Anh xử lý môi trường mơ hồ / nhiều việc thế nào?"** → CiteFlow/CVTOT: startup nhỏ, làm nhiều vai (FE + SEO + hỗ trợ dự án AI HR), vẫn ship được sản phẩm production.
- **"Điểm yếu của anh?"** (trả lời thật + tích cực): *"Giai đoạn vừa rồi tôi dựa nhiều vào công cụ AI để ship nhanh, nên đang chủ động ôn lại nền tảng JS/TS và React internals để hiểu sâu hơn cái mình viết."* → Cho thấy **tự nhận thức + chủ động**, nhà tuyển dụng đánh giá cao.

## 6. Lộ trình 3 tuần (mỗi ngày 2-3h là đủ)

**Tuần 1 — Vá nền tảng (để không sợ live-coding)**
- JavaScript/TypeScript core: closure, `this`, async/await, Promise, array methods, type cơ bản.
- React core: `useState`/`useEffect`/`useMemo`/`useCallback`, render & re-render, key, lifting state, controlled inputs.
- Mỗi ngày: 1 bài nhỏ tự code TAY (không AI) — vd: todo list, debounce search, fetch + loading/error.

**Tuần 2 — Củng cố + chuẩn bị "đào sâu dự án"**
- Ôn: REST, HTTP status, fetch/axios, React Query (cache/invalidate), Git (branch/merge/rebase cơ bản).
- DSA mức phỏng vấn FE: array/string/hashmap, độ phức tạp Big-O (chỉ cần cơ bản).
- Viết sẵn **"project deep-dive"**: vẽ kiến trúc EmoEase & CiteFlow, giải thích được TỪNG quyết định (vì sao React Query, vì sao cấu trúc này).

**Tuần 3 — Luyện phỏng vấn + bắt đầu rải đơn**
- 3-4 buổi **mock interview** (tự quay video hoặc nhờ bạn): 1 câu kỹ thuật + 1 câu hành vi (STAR).
- Luyện **English nói**: tập giới thiệu bản thân 60 giây + mô tả 1 dự án bằng tiếng Anh (5 phút/ngày).
- **Bắt đầu apply** song song (đừng đợi "hoàn hảo"): dùng hệ thống chấm điểm + may đo CV theo JD.
